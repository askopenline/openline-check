    Vos questions sur l'eSIM

    Comment savoir si mon téléphone est compatible eSIM ?

    Recherchez votre marque et votre modèle ci-dessus, ou le code modèle indiqué dans les réglages de votre téléphone. Vous pouvez aussi composer le *#06# : si une ligne EID apparaît, l'appareil dispose d'une puce eSIM.

    Qu'est-ce qu'un EID ?

    L'EID (identifiant eUICC) est un numéro à 32 chiffres qui identifie la puce eSIM intégrée à votre appareil. Seuls les appareils équipés d'une eSIM en possèdent un.

    Pourquoi un même modèle peut-il différer selon les pays ?

    Les constructeurs commercialisent des versions régionales. La plupart des iPhone vendus en Chine continentale, à Hong Kong et à Macao utilisent deux SIM physiques au lieu de l'eSIM, tandis que les iPhone 14 et ultérieurs vendus aux États-Unis fonctionnent uniquement en eSIM. Vérifiez le code modèle exact.

    Mon téléphone doit-il être désimlocké ?

    Oui. Un téléphone bloqué par un opérateur peut refuser les profils eSIM d'autres fournisseurs, même s'il possède une puce eSIM. Demandez à votre opérateur de le débloquer avant d'installer une nouvelle eSIM.

    Comment installer une eSIM Openline ?

    Si votre appareil est compatible et désimlocké, achetez un forfait sur openline.com et scannez le code QR dans Réglages › Données cellulaires (iPhone) ou Paramètres › Connexions › Gestionnaire de carte SIM (la plupart des téléphones Android).
